## ⚖️ Ethical Hacking

Todas las actividades de este repositorio tienen un propósito **educativo y de formación en ciberseguridad**.

Las pruebas de seguridad deben realizarse únicamente:

- ✅ Con autorización.
- ✅ Dentro del alcance establecido.
- ✅ De forma ética y responsable.
- ✅ Sin afectar sistemas o información de terceros.
- ✅ Respetando la confidencialidad de la información.

> 🔒 **Primero se analiza, luego se planifica y finalmente se actúa con autorización.**
