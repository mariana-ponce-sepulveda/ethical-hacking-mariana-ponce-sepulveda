# 🛡️ Actividad 01 — Análisis y Planificación del Pentest

### 📌 Descripción

Actividad enfocada en comprender las etapas iniciales de un **Pentest**, considerando la planificación, definición del alcance, reconocimiento y metodología de trabajo.

### 🎯 Objetivos

* Comprender la importancia de establecer un alcance (*scope*).
* Identificar información relevante antes de realizar pruebas.
* Planificar las diferentes etapas de un Pentest.
* Reconocer riesgos y restricciones del entorno.
* Aplicar principios de Ethical Hacking de manera responsable.

# 🔍 Actividad 02 — Nmap Recon Challenge

### 📌 Descripción

Actividad práctica orientada al **reconocimiento de redes y servicios mediante Nmap**, utilizando el entorno autorizado:

```text
scanme.nmap.org
```

El desafío contempla la realización y análisis de **10 retos de reconocimiento y escaneo**.

### 🎯 Objetivos

* Comprender el funcionamiento de Nmap.
* Identificar hosts y puertos disponibles.
* Analizar servicios y versiones.
* Utilizar diferentes tipos de escaneo.
* Explorar scripts NSE.
* Realizar detección de sistema operativo.
* Analizar el comportamiento de los escaneos frente a mecanismos de filtrado.

### 🧪 Retos realizados

Los retos incluyen diferentes técnicas de reconocimiento, entre ellas:

* 🔎 Ping Scan
* ⚡ SYN Scan
* 🔢 Escaneo de puertos
* 🧩 Detección de versiones
* 🖥️ Detección de sistema operativo
* 📜 Scripts NSE
* 🎯 Escaneo agresivo
* 🛡️ Análisis de comportamiento frente a firewall

### 📊 Entregable

El informe técnico contiene:

* Tabla resumen de los retos realizados.
* Comandos utilizados.
* Resultados obtenidos.
* Capturas de evidencia.
* Análisis de los resultados.
* Observaciones sobre el comportamiento frente a mecanismos de filtrado.

# ⚖️ Principios de Ethical Hacking

Todas las actividades realizadas en este repositorio tienen un propósito **educativo y de formación en ciberseguridad**.

Las pruebas de seguridad deben realizarse únicamente:

* ✅ Con autorización explícita.
* ✅ Dentro del alcance (*scope*) establecido.
* ✅ Sobre sistemas permitidos.
* ✅ De forma ética y responsable.
* ✅ Respetando las condiciones definidas para cada práctica.
* ❌ Sin acceder, modificar o afectar sistemas fuera del alcance autorizado.

> 🔒 **Primero se analiza, luego se planifica y finalmente se actúa con autorización.**
