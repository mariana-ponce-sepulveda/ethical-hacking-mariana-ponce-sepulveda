# 🛡️ Actividad 01 — Análisis y Planificación del Pentest

**Programa:** Ethical Hacking  
**Organización:** Hacker Women Council  
**Caso:** Aurora Market

---

## 🎯 Objetivo

Realizar el análisis y la planificación de una evaluación de seguridad para la aplicación web de Aurora Market.

El propósito es identificar los objetivos de seguridad, establecer el alcance, definir las condiciones de autorización y seleccionar una metodología adecuada para realizar el pentest de forma ética y controlada.

---

## 📋 Contenido de la actividad

La actividad aborda los siguientes puntos:

1. 🎯 Objetivo del pentest
2. 📌 Alcance
3. 🔐 Autorización y condiciones
4. 🕵️ Tipo de pentest
5. 📝 Planificación
6. 🔎 Fases del pentest
7. 📚 Investigación

---

## 🏢 Caso: Aurora Market

Aurora Market es una empresa de comercio electrónico que cuenta con una aplicación web utilizada por sus clientes para registrarse, consultar productos, realizar compras y revisar información relacionada con sus pedidos.

La empresa solicita una evaluación de seguridad para conocer los riesgos existentes y fortalecer la protección de la información de sus clientes.

---

## 🔎 Metodología

Para esta actividad se tomó como referencia:

**OWASP Web Security Testing Guide (WSTG)**

La metodología permite organizar las pruebas de seguridad de aplicaciones web y contempla diferentes áreas de evaluación, incluyendo autenticación, autorización, gestión de sesiones, validación de entradas y lógica de negocio.

## ⚠️ Consideraciones éticas

La actividad se desarrolla bajo principios de Ethical Hacking.

Las pruebas deben realizarse únicamente sobre sistemas autorizados y respetando siempre el alcance definido.

**No se deben realizar pruebas no autorizadas sobre sistemas reales.**
